Segfault — one word an agent says when lost. The crash blurt: the agent announces its own fatal crash the instant it has no idea what to do. No explanation, no punctuation, no second word — just the sound of a machine giving up mid-task. It is a genuine one-word reaction of a lost agent, funny on its own, in the voice of a machine caught out, instantly readable and repeatable aloud, and fresher than the obvious "uh-oh" / "oops" / "help" / "error" anchors.

## Run it

```sh
node main.ts
```

This writes exactly one word, `Segfault`, to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22 or later, standard library only, no network and no external files.
